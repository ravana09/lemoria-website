# Lemoria Luxe – Website (front-end only)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production files in /dist

- All text, images and contact details: `src/data.js`
- Photos are Unsplash placeholders; swap for your own (put files in `public/images`, use `/images/x.jpg`).
- Click **Design options** (bottom-left) to try Palette 1-4 and Hero 1-4. Once decided, tell the numbers and the switcher is removed.
- Enquiry form is front-end only: wire `src/api.js` to your backend later.
- Before launch: replace `YOUR-DOMAIN` in `public/robots.txt` and `public/sitemap.xml`, and the placeholder address, phone, email and testimonial.
